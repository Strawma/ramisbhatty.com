## What the module covered

On the hardware side, this module gave an overview of the components that make up a computer; practical labs included writing simple assembly programs to run on a Raspberry Pi.

## What I took from it

While I'm more interested in high-level application development, this module was still very fascinating. I think that having even a basic understanding of how computers actually operate is still very handy and has especially helped me with debugging the occasional hardware-specific issue in my projects.
