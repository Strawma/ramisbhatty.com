## What the module covered

This module is essentially a continuation of COMP1202, covering more advanced programming concepts and techniques. This included topics such as GUI programming, unit testing, and software design patterns. The majority of this module was taught through Java with a coursework project that required the implementation of a simple GUI-based game using JavaFX. A small portion of the module also covered C programming, with a focus on memory management and pointers.

## What I took from it

The introduction to build tools and unit testing that this module provided has been very useful. Previous to this module, I had only ever really run code through an IDE. Now I am able to use build tools such as Maven to compile, run and test my code from the command line, which has been very useful for my personal projects.
