## What the module covered

This module built on Programming I with event-driven GUI programming, file and network I/O, concurrency, testing, and software design. Most of the teaching used Java, with a smaller introduction to C covering pointers and manual memory management.

The coursework was TetrECS, a JavaFX block-placement game with piece rotation, line clearing, scoring, and timed turns. My implementation included sound, saved high scores, and a multiplayer lobby connected to the course server over WebSockets. The game brought together a separate model for the game state, reusable interface components, and listeners that connected the two.

## What I took from it

The introduction to build tools and unit testing has been particularly useful. Before this module, I mostly ran code through an IDE. Learning to build and run projects with Maven, and to write tests with JUnit, gave me a workflow I could also use from the command line for personal projects.
