## What the module covered

This module introduced the basics of database design and management. This included theoretical concepts such as normalisation and relational algebra.

Furthermore, we were also assigned practical coursework covering actually handling databases, including querying and modifying them using SQL, as well as broader tasks involving managing data in a Unix environment.

## What I took from it

Nowadays, I frequently self-host services like game servers and random apps on my own debian home server using Docker containers. I have COMP1204 to thank for giving me the confidence to do this, as it showed me how powerful, convenient and accessible command line tools and containers can be for managing services!
